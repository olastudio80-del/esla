# Справочник лекарств

`src/data/registry.json` собирается из выгрузки государственного реестра
лекарственных средств Узбекистана (референтные цены). Исходный файл лежит
рядом — `source.xlsx`.

## Как обновить новой выгрузкой

Положить новый файл вместо `source.xlsx` и выполнить из корня проекта:

```bash
python3 -I scripts/registry/extract.py scripts/registry/source.xlsx /tmp/extracted.json
```

```bash
npx tsx scripts/registry/build.ts /tmp/extracted.json src/data/registry.json
```

Затем `npm test` — тесты проверяют, что знакомые препараты находятся
и что данные целы.

## Что переносится, а что нет

Берутся торговое название, действующее вещество, форма выпуска и
зарегистрированные дозировки. **Цены, производители и номера регистрации
не переносятся**: приложение помогает правильно записать назначенное
врачом, а не выбирать лекарство и тем более не торговать им. Цены вдобавок
устаревают, а устаревшая цена в приложении о здоровье вводит в заблуждение.

## Почему ключи поиска считаются на TypeScript

`build.ts` сворачивает названия той же функцией `fold`, что работает в
приложении. Вторая реализация на Python неизбежно разошлась бы с первой,
и поиск перестал бы находить то, что лежит в данных, — молча и не сразу.

## Разбор формы и дозировки

Форма ищется по ключевым словам в описании упаковки, а дозировка — от
первой цифры после неё. Позиционный разбор («всё до первой цифры — форма»)
рассыпается на марках с цифрой в названии: «ОМЕГАСТ® 20», «Нексогет IV».
